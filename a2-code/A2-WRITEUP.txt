Problem 2: kmeans_serial vs kmeans_mpi
======================================

  Discuss how you chose to parallelize your serial version of K-means in
  the program `kmeans_mpi.c'. Answer the following questions briefly.
  1. How is the input and output data partitioned among the processors?

      I read in all the input in the the root process, then divided it up by individual data, 
      spreading rows of data as evenly as possible between different processers. Each process had its own copy 
      of the KMClust struct which had to be updated each iteration to gaurantee that all processors had consistent features.
      The output required communicating how many data were in each cluster to the root node so that it could print this out, and
      save to the output file.

  2. What communication is required throughout the algorithm?

      The first communications that had to be done were the root processor communicating important metrics relating to 
      how much of the total data each processor would get. Once that was figured out, the root had to scatter its data to all 
      the procesors so that they could start working on their respective chunk of the data. Throughout the algorithm, the processers 
      had to communicate the updated feature centers of their clusters, as well as the number of their data in each cluster, so that 
      all the processors could update their own KMClust struct and make the correct assignment to the data in the next step. They also 
      had to reduce their counts for each cluster so that the root processor could print out the updated number of members of each cluster. 
      For each iteration, all the procs had to all reduce the number of changes they encountered, so that it would be known by all procs whether 
      they were to continue or not. This avoided the case where one proc would have had no changes, but another one would have had a few and 
      needed to keep on going. At the end, an all gather was needed to collect in the root processor which cluster each of the data was put into 
      once the main algorithm finished. This was needed in order to make the confusion matrix and save the results to the output file.

  3. Which MPI collective communication operations did you employ?
      I used MPI_Init(), MPI_Comm_rank (), MPI_Comm_size (),  MPI_Bcast(), MPI_Scatterv(), MPI_Allreduce(), MPI_Gatherv(), and MPI_Finalize().
